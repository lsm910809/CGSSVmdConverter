# CGSS VMD Converter

A small tool for converting character animation data from  
**THE iDOLM@STER Cinderella Girls: Starlight Stage**  
(CGSS / デレステ) into **MikuMikuDance VMD** motion files.

**Current version: v0.1.0**

> [!NOTE]
> This tool currently converts **character skeletal motion only**.
> Facial/lip-sync animation and camera motion are **not yet supported**.

## Features

CGSS VMD Converter currently supports:

- CGSS Unity Legacy `AnimationClip` (`.anim`) → MMD `.vmd`
- Body and upper-body motion
- Head and neck motion
- Shoulder and arm motion
- Hand and finger motion
- FK leg motion
- Root / center translation
- CGSS → MMD coordinate conversion
- CGSS → MMD rest-pose / bone-space conversion
- Conversion to an MMD-style A-pose skeleton
- 30 FPS and 60 FPS output
- Automatic disabling of MMD leg and toe IK

The generated VMD explicitly disables:

- `左足ＩＫ`
- `右足ＩＫ`
- `左つま先ＩＫ`
- `右つま先ＩＫ`

CGSS dance motion is treated as **FK-driven**. The converter does not
generate MMD leg IK motion, since doing so would interfere with the original
leg rotations contained in the CGSS animation.

## Obtaining CGSS Animation Data

This program does **not** download or include CGSS game assets.

The animation data used during development was obtained using:

[cgss-resource-tool](https://github.com/BA-Momoi/cgss-resource-tool)

`cgss-resource-tool` can be used to obtain the relevant CGSS resources as
Unity `.unity3d` asset bundles.

It also bundles **AssetStudio**, which can be used to inspect the downloaded
Unity assets and export the required `AnimationClip` as a Unity `.anim` file.

The workflow used with this converter is:

    CGSS resources
        ↓
    cgss-resource-tool
        ↓
    .unity3d asset bundle
        ↓
    bundled AssetStudio
        ↓
    AnimationClip exported as .anim
        ↓
    CGSS VMD Converter
        ↓
    .vmd
        ↓
    MikuMikuDance

### Basic extraction workflow

1. Use `cgss-resource-tool` to obtain the desired CGSS `.unity3d` resource.
2. Open/extract the asset bundle using the AssetStudio functionality bundled
   with `cgss-resource-tool`.
3. Locate the desired character `AnimationClip`.
4. Export it as a Unity `.anim` file.
5. Open the `.anim` file in CGSS VMD Converter.
6. Convert it to `.vmd`.
7. Load the resulting motion into MikuMikuDance.

No CGSS game assets are included in this repository.

## Usage

1. Launch **CGSS VMD Converter**.
2. Click **Browse**.
3. Select an extracted CGSS `.anim` file.
4. Select the desired output frame rate.
5. Click **Convert to VMD**.
6. Choose where to save the resulting `.vmd`.
7. Load the VMD into MikuMikuDance.

The generated VMD contains the converted skeletal motion and automatically
sets MMD's leg and toe IK systems to **OFF**.

## macOS

The macOS release is provided as a **Universal 2** application and supports
both Apple Silicon (`arm64`) and Intel (`x86_64`) Macs.

The application is **ad-hoc signed but is not notarized by Apple**.

Because the application is not notarized, macOS Gatekeeper may block it when
it is opened for the first time after being downloaded.

If macOS blocks the application:

1. Try to open **CGSS VMD Converter** once.
2. Open **System Settings → Privacy & Security**.
3. Scroll down to the **Security** section.
4. Find the message stating that **CGSS VMD Converter** was blocked.
5. Click **Open Anyway**.
6. Confirm that you want to open the application.

This should normally only be necessary for the first launch.

You do **not** need to disable Gatekeeper globally.

## Why is IK disabled?

The CGSS dance animations handled by this converter animate the legs using
bone rotations rather than MMD-style leg IK.

The relevant FK bone chains are:

    左足
      ↓
    左ひざ
      ↓
    左足首

and:

    右足
      ↓
    右ひざ
      ↓
    右足首

If MMD's leg or toe IK remains enabled, the MMD IK solver can interfere with
these rotations and produce an incorrect pose.

For this reason, the generated VMD contains an IK state at frame 0 that
explicitly disables:

    左足ＩＫ
    右足ＩＫ
    左つま先ＩＫ
    右つま先ＩＫ

No leg IK motion is generated by the converter.

## CGSS → MMD Conversion

CGSS and MMD do not use identical skeletons, coordinate systems, or
rest-pose conventions.

Simply copying the Unity animation quaternions into a VMD file does **not**
produce a correct MMD motion.

CGSS VMD Converter therefore performs:

1. Unity/CGSS coordinate-system conversion
2. CGSS bone → MMD bone mapping
3. Per-bone rest/bind-space correction
4. CGSS rest-pose → MMD-style A-pose conversion
5. Root movement → MMD center movement conversion
6. Animation sampling at the selected output frame rate
7. VMD quaternion continuity handling
8. VMD motion generation

This conversion is specifically calibrated for the CGSS character animation
skeleton.

## Compatibility

### Desktop platforms

Prebuilt releases are currently provided for:

- **macOS Universal 2** — Apple Silicon (`arm64`) and Intel (`x86_64`)
- **Windows x64** — Intel/AMD 64-bit Windows
- **Windows ARM64** — native ARM64 Windows

The macOS Universal 2 release contains both architectures in a single
application.

Windows x64 and Windows ARM64 are provided as separate builds.

### Animation compatibility

This tool is designed specifically for character motion data from
**THE iDOLM@STER Cinderella Girls: Starlight Stage**.

It is **not intended to be a general-purpose Unity AnimationClip → VMD
converter**.

Animation data from unrelated Unity games or projects may use different:

- Skeleton structures
- Bone names
- Rest poses
- Coordinate systems
- Animation hierarchies
- AnimationClip formats

and therefore should not be expected to convert correctly.

The input is expected to be the Unity Legacy `.anim` format used by the CGSS
motion data tested with this converter.

## Current Limitations

### Facial animation / lip-sync

Facial animation and lip-sync are **not currently converted**.

The skeletal character AnimationClip used by this converter does not provide
the facial/lip data in a form currently handled by the program.

The generated VMD therefore does not contain MMD facial morph animation.

### Camera motion

CGSS camera motion is also **not currently converted**.

The generated VMD contains character motion only and does not include an MMD
camera track.

### Other Unity animations

The converter contains CGSS-specific bone mappings and rest-pose corrections.

It should therefore not be treated as a universal Unity-to-MMD animation
converter.
